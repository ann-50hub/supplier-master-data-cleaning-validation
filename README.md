# Supplier Master Data Cleaning & Validation

## Overview

Procurement data-quality portfolio project focused on cleaning, standardizing, and validating supplier master data using Microsoft Excel.

## Objectives

- Clean and standardize supplier master records
- Identify duplicate supplier records
- Validate supplier information
- Identify incomplete or inconsistent data
- Apply validation rules to supplier master data
- Measure overall data quality
- Flag records requiring further review

## Tools Used

- Microsoft Excel
- Data Cleaning
- Data Validation
- Duplicate Detection
- Excel Formulas
- Pivot Tables
- Data Quality Analysis
- Dashboarding

## Key Analysis

The project evaluates:

- Supplier name standardization
- Supplier email validation
- Tax ID validation
- Payment terms
- Bank details
- Supplier ratings
- Duplicate supplier records
- Missing or inconsistent information
- Records requiring review
- Overall supplier data quality

## Validation Process

The supplier master data was reviewed using defined validation rules to identify:

- Missing information
- Invalid email formats
- Inconsistent supplier details
- Duplicate records
- Invalid or inconsistent payment terms
- Data requiring manual review

## Dashboard

The data-quality dashboard summarizes validation results and highlights supplier records requiring attention.

## Dataset

This project uses a synthetic supplier master dataset created for learning and portfolio demonstration purposes.

## Project File

The Excel workbook contains the raw supplier master data, cleaned supplier data, validation summary, duplicate checks, and data-quality dashboard.
